# All Systems Flashcards

Internal medicine flashcards for 10 systems (chest, cardio, hepatology, GIT, neuro, nephro, hematology, infections, rheumatology, endocrinology): 1A, 1B and IM Paper 1 past questions.

Open `index.html` (or the GitHub Pages link). Tap a card to flip it, then mark Pass or Fail; progress is saved in your browser.

## IM Cases

`cases/` holds the IM problem-solving cases deck (Cardio, Chest, GIT, Hepatology, Neuro): the case on the front, the diagnosis and the answers on your Z-book pages on the back. Open `cases/index.html` (or the GitHub Pages link + `/cases/`).

## MCQ

`MCQ/` holds the Paradox internal medicine MCQ quiz (past-paper questions by system, with answers, explanations, hard-question marking and PDF export). Open `MCQ/index.html` (or the GitHub Pages link + `/MCQ/`). Progress is saved in your browser. To share progress between devices, open "Sync progress across devices" and connect each device with the same GitHub key (classic token with only the `gist` permission); progress is kept in a private gist named `mcq-progress.json`.

## Derma

`Derma/` holds the Paradox dermatology MCQ quiz: Kasr Al-Ainy past-exam questions 2020–2026, each question once with how many exams it came in and which years, answers, explanations with the derma department book page, hard-question marking and PDF export. Open `Derma/index.html` (or the GitHub Pages link + `/Derma/`). Progress is saved in your browser, separately from the IM MCQ. Sync between devices works the same way as the MCQ (same GitHub key); derma progress is kept in its own private gist file `derma-progress.json`.

### Derma photo atlas

`Derma/atlas/` holds the derma photo atlas flashcards: 387 pictures from the Derma 2026 Photo Atlas in 16 chapters. The front is the picture; tap it to see the disease, chapter and notes page, then mark Pass or Fail. Failed cards come back a few cards later and stay in the Failed list until passed. Pick chapters, show only new/failed/passed cards, Shuffle or Unshuffle back to book order. Progress syncs between devices with the same GitHub key (private gist file `derma-atlas-progress.json`). Open it from the "📷 Photo atlas" button in the Derma quiz, or the GitHub Pages link + `/Derma/atlas/`.

## ClinPath

`ClinPath/` holds the Paradox clinical pathology MCQ quiz: every MCQ and case question from the Kasr Al-Ainy department question book, plus past exams from 2018 to 2025 (written papers and oral sheets with choices). Each question appears once, with the exams it came in; case questions show their lab report. Answers, short explanations and the Clinical Pathology Part I page are under each question. Open `ClinPath/index.html` (or the GitHub Pages link + `/ClinPath/`). Progress is saved in your browser, separately from the other quizzes; sync between devices uses the same GitHub key, in its own private gist file `clinpath-progress.json`.

## ECG

`ECG/` holds the ECG flashcards: the 39 ECGs of the ECG Practice Pack in its three tiers (Tier 1 must know #1–18, Tier 2 likely #19–29, Tier 3 recognize only #30–39). The front is the case and the ECG; "Show hint" reveals the pack's clue. Tap the card for the full comment from the pack, and for the six Dr. Hala past-exam ECGs also her own comment as written. Every ECG is the practice pack's own image, untouched (no sharpening or clean-up). #14 is shown as a true redraw (trace re-traced on a true-scale grid, lead names typed). #6, #7, #18, #19, #25, #27 and #29 have their grid redrawn on a clean true-scale grid with the original trace and labels untouched, and #13 is straightened (perspective corrected) with a redrawn grid. Each of these has "View original" to see the photo. "Enlarge" opens the ECG full size to pinch and scroll. Pass/Fail, Failed list, Past-exams filter, Shuffle/Unshuffle and device sync work like the Derma atlas (private gist file `ecg-progress.json`, same GitHub key). Open `ECG/index.html` (or the GitHub Pages link + `/ECG/`).

## Notes

`Notes/` is a PDF writing page for iPad with a stylus: open any PDF from Files and write on it with Pen, Marker, Pencil, straight line and Eraser, with Undo/Redo, colours and thickness. Pinch and double-tap zoom are switched off so drawing circles or S shapes doesn't zoom the page; use the − / ＋ buttons to zoom and ✋ to scroll. Notes are saved automatically in this browser, and "⤓ PDF" downloads a copy of the PDF with your writing on it. Open `Notes/index.html` (or the GitHub Pages link + `/Notes/`).

## Surgery

`Surgery/` holds the Surgery flashcards: the plastic surgery questions of the 2026 surgery essay bank (Class A, B and C). The front is the question; the back is the matching section of the surgery book. The answers are stored encrypted and open with a password, which each device remembers after the first time. Class and topic filters, Pass/Fail, Failed list, Shuffle/Unshuffle and the drawing tools work like the IM deck. Progress syncs between devices with the same GitHub key (private gist file `surgery-progress.json`). Open `Surgery/index.html` (or the GitHub Pages link + `/Surgery/`).

## SurgeryMCQ

`SurgeryMCQ/` holds the Paradox surgery MCQ quiz from Dr Amr Mohsen's Surgery MCQ book: 640 questions split into Paper 1 (350) and Paper 2 (290), with a set per chapter, plus "Paper 1 topics" / "Paper 2 topics" dropdowns to tick any mix of chapters from both papers. After each answer it shows the book's own explanation (typed out, with its page number); where the book's explanation was too short, an added explanation is shown separately and labelled as not from the book. Questions that came in the 2025 final exam are tagged (e.g. "Paper 1 · 2025 (Q7)"). Paper 3 chapters (cardiothoracic, urology, orthopaedics, neurosurgery) and the Clinical Surgery / Surgical Radiology chapters are not included. Open `SurgeryMCQ/index.html` (or the GitHub Pages link + `/SurgeryMCQ/`). Same options as the other quizzes: hard marks, wrong-only, hide answered, show answers, PDF download, dark mode. Progress is saved separately; sync between devices uses the same GitHub key, in its own private gist file `surgery-mcq-progress.json`.
