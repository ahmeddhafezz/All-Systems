# All Systems Flashcards

Internal medicine flashcards for 10 systems (chest, cardio, hepatology, GIT, neuro, nephro, hematology, infections, rheumatology, endocrinology): 1A, 1B and IM Paper 1 past questions.

Open `index.html` (or the GitHub Pages link). Tap a card to flip it, then mark Pass or Fail; progress is saved in your browser.
