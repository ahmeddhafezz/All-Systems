# All Systems Flashcards

Internal medicine flashcards for 10 systems (chest, cardio, hepatology, GIT, neuro, nephro, hematology, infections, rheumatology, endocrinology): 1A, 1B and IM Paper 1 past questions.

Open `index.html` (or the GitHub Pages link). Tap a card to flip it, then mark Pass or Fail; progress is saved in your browser.

## IM Cases

`cases/` holds the IM problem-solving cases deck (Cardio, Chest, GIT, Hepatology, Neuro): the case on the front, the diagnosis and the answers on your Z-book pages on the back. Open `cases/index.html` (or the GitHub Pages link + `/cases/`).

## MCQ

`MCQ/` holds the Paradox internal medicine MCQ quiz (past-paper questions by system, with answers, explanations, hard-question marking and PDF export). Open `MCQ/index.html` (or the GitHub Pages link + `/MCQ/`). Progress is saved in your browser. To share progress between devices, open "Sync progress across devices" and connect each device with the same GitHub key (classic token with only the `gist` permission); progress is kept in a private gist named `mcq-progress.json`.

## Derma

`Derma/` holds the Paradox dermatology MCQ quiz: Kasr Al-Ainy past-exam questions 2020–2026, each question once with how many exams it came in and which years, answers, explanations with the derma department book page, hard-question marking and PDF export. Open `Derma/index.html` (or the GitHub Pages link + `/Derma/`). Progress is saved in your browser, separately from the IM MCQ. Sync between devices works the same way as the MCQ (same GitHub key); derma progress is kept in its own private gist file `derma-progress.json`.

## ClinPath

`ClinPath/` holds the Paradox clinical pathology MCQ quiz: every MCQ and case question from the Kasr Al-Ainy department question book, plus past exams from 2018 to 2025 (written papers and oral sheets with choices). Each question appears once, with the exams it came in; case questions show their lab report. Answers, short explanations and the Clinical Pathology Part I page are under each question. Open `ClinPath/index.html` (or the GitHub Pages link + `/ClinPath/`). Progress is saved in your browser, separately from the other quizzes; sync between devices uses the same GitHub key, in its own private gist file `clinpath-progress.json`.
